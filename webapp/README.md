# KryptonxWatch web app

Recorded-video security review dashboard. From this directory, run `npm install` and `npm run dev`, then open http://localhost:3000.

The bundled recordings and detections are simulated. Uploaded videos are stored in your browser and are not analyzed until a detection service is connected. See [project guidance](CLAUDE.md) and [feature roadmap](.plans/webapp-roadmap.md).
