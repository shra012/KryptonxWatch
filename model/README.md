# Model assets

Model-specific code, environments, plans, and run outputs are grouped by model:

- [Qwen3.8-27B-INT4](Qwen3.8-27B-INT4/README.md): Qwen experiment code, environment, plans, and runs.
- [GLM-4.5-VL](GLM-4.5-VL/README.md): GLM pilot and quantization code, environment, plans, and runs.
- [openrouter-bakeoff](openrouter-bakeoff/README.md): zero-shot comparison of 12 open VLMs that fit the GB10 against HawkWatch, run through the web app's analysis pipeline; the recommended local model.

Shared study data remains in `study/`, and shared certificates remain in `certs/`.
